# PDF түбіртектерін өңдеу арқылы курстарды сатуға арналған Kaspi Telegram боты.

## Құрылымы

```text
project/
├── app/
│   ├── __init__.py
│   ├── config.py
│   ├── storage.py
│   ├── verifier.py
│   ├── keyboards.py
│   └── handlers.py
├── main.py
├── requirements.txt
├── .env.example
├── .gitignore
└── run_windows.bat
```

## Windows-та орнату

1. ZIP архивін шығарыңыз.
2. `.env.example` файлын `.env` деп көшіріңіз (немесе `run_windows.bat` автоматты түрде ұсынады).
3. `.env` ішінде `TG_BOT_TOKEN` және `ADMIN_IDS` мәндерін енгізіңіз.
4. `run_windows.bat` іске қосыңыз.

Қолмен іске қосу:

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

## Жаңа курс қосу

Әкімші ботта:

```text
/add_course c5|Жаңа сабақ|7500|https://kaspi.kz/pay|https://t.me/+abc|-1001234567890|30
```

Параметрлер реті: `key|title|amount|pay_url|channel_link|chat_id|expires_days`.

Курс қосылған соң бот осы курсқа тиесілі PDF чек жіберуді сұрайды. PDF-тен сатушының ИП атауы мен 12 таңбалы ЖСН/БСН-ын автоматты түрде алуға тырысады. Алынған деректерді курс редакторындағы **🧾 ИП-ны чектен алу** батырмасы арқылы жаңартуға болады. Әрекетті `/cancel` арқылы тоқтатуға болады.

## Маңызды ескерту

- Чектен мәтін немесе QR деректерін шығару төлемнің түпнұсқалығын өздігінен кепілдендірмейді.
- Сатушы деректерін міндетті түрде тексеріңіз. Kaspi веб-бетінің құрылымы өзгерсе, автоматты талдау істемей қалуы мүмкін.
- Нақты төлемді растау үшін `verifier.py`-дегі тексеру нәтижесін және сатушының ЖСН/БСН-ын мұқият тексеріңіз.
- Алдымен ботты тест арнада және тест төлеммен тексеріңіз.

## Командалар

- `/start` — негізгі мәзір
- `/my` — менің сабақтарым
- `/stats` — статистика (әкімші)
- `/add_course ...` — курс қосу (әкімші)
- `/delete_course <key>` — курсты жою (әкімші)
- `/grant <key>` — грант сілтемесін жасау (әкімші)
- `/cancel` — ағымдағы әрекетті тоқтату
