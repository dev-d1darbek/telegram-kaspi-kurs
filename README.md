## 🚀 Жоба туралы

**Telegram Kaspi Kurs Bot** — Kaspi арқылы төлем жасаған пайдаланушылардың **PDF түбіртектерін автоматты түрде тексеретін** және сәтті төлемнен кейін оларға **жабық курс каналына/чатына қолжетімділік беретін** Telegram-бот.

Жоба білім беру бизнесіне арналған: мұғалімдер, инфобизнесмендер және онлайн-курс сатушылар үшін төлемді растау процесін толық автоматтандырады.

### Негізгі ағын

```
Пайдаланушы → Курс таңдайды → Kaspi сілтемесіне өтеді → Төлем жасайды
     ↓
PDF чекті ботқа жібереді → Бот чекті талдайды → Сатушының ЖСН/БСН-ын тексереді
     ↓
✅ Сәтті → Жабық каналға/чатқа қолжетімділік беріледі
❌ Сәтсіз → Пайдаланушыға қате туралы хабарлама
```

| Категория | Мүмкіндік |
|---|---|
| 📚 **Курстар** | Курс қосу, жою, бағасын, мерзімін басқару |

## 🏗️ Архитектура

```
┌──────────────┐       ┌──────────────┐       ┌──────────────┐
│  Telegram    │──────▶│   aiogram    │──────▶│  handlers.py │
│   Client     │◀──────│   Router     │◀──────│              │
└──────────────┘       └──────────────┘       └──────┬───────┘
                                                     │
                       ┌─────────────────────────────┼─────────────────────┐
                       ▼                             ▼                     ▼
                ┌──────────────┐              ┌──────────────┐      ┌──────────────┐
                │  verifier.py │              │  storage.py  │      │ keyboards.py │
                │ (PDF талдау) │              │ (Дерекқор)   │      │ (UI)         │
                └──────────────┘              └──────────────┘      └──────────────┘
```

**Негізгі модульдер:**
- `app/config.py` — `.env` конфигурациясы
- `app/storage.py` — курс/пайдаланушы деректерін сақтау
- `app/verifier.py` — PDF чекті талдау және сатушыны тексеру
- `app/keyboards.py` — inline/reply батырмалар
- `app/handlers.py` — Telegram оқиғаларын өңдеу
- `main.py` — кіру нүктесі

## 🚀 Жылдам бастау

### 1. Репозиторийді клондау

```bash
git clone https://github.com/dev-d1darbek/telegram_kaspi_kurs.git
cd telegram_kaspi_kurs
```

### 2. Виртуалды орта жасау

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate
```

### 3. Тәуелділіктерді орнату

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. `.env` файлын дайындау

```bash
cp .env.example .env
# .env файлын редакторда ашып, мәндерді толтырыңыз
```

### 5. Ботты іске қосу

```bash
python main.py
```

**Windows-та** — `run_windows.bat` файлын екі рет басыңыз (ол `.env` файлын автоматты түрде ұсынады).

## ⚙️ Конфигурация

Барлық құпия параметрлер `.env` файлында сақталады.

| Айнымалы | Міндетті | Сипаттама |
|---|:---:|---|
| `TG_BOT_TOKEN` | ✅ | [@BotFather](https://t.me/BotFather) арқылы алынатын токен |
| `ADMIN_IDS` | ✅ | Әкімшілердің Telegram ID-і (үтір арқылы) |
| `DB_PATH` | ❌ | Дерекқор файлының жолы (әдепкі: `data/bot.db`) |
| `LOG_LEVEL` | ❌ | `INFO` \| `DEBUG` \| `WARNING` \| `ERROR` |

> ⚠️ `.env` файлын **ешқашан** Git-ке жібермеңіз. Ол `.gitignore`-та.

## 📚 Курс қосу

Курс қосу пәрменінің форматы:

```
/add_course key|title|amount|pay_url|channel_link|chat_id|expires_days
```

**Мысал:**
```
/add_course c5|Жаңа сабақ|7500|https://kaspi.kz/pay/abc|https://t.me/+abc|-1001234567890|30
```

**Параметрлер:**

| Параметр | Сипаттама |
|---|---|
| `key` | Курстың бірегей кілті (мыс. `c5`) |
| `title` | Курстың атауы |
| `amount` | Бағасы (теңге) |
| `pay_url` | Kaspi төлем сілтемесі |
| `channel_link` | Жабық каналдың шақыру сілтемесі |
| `chat_id` | Каналдың/чаттың ID-і |
| `expires_days` | Қолжетімділік мерзімі (күнмен) |

Курс қосылғаннан кейін бот осы курсқа тиесілі **PDF чек жіберуді сұрайды**. PDF-тен сатушының **ИП атауы мен 12 таңбалы ЖСН/БСН-ы** автоматты түрде алынуға тырысады.

Алынған деректерді курс редакторындағы **«ИП-ны чектен алу»** батырмасы арқылы жаңартуға болады.

## 🧾 PDF чекті тексеру

1. Пайдаланушы курсқа төлем жасайды
2. Kaspi-ден **PDF түбіртек** жүктеп алады
3. Оны ботқа жібереді
4. Бот PDF-ті талдап, мыналарды тексереді:
   - Сатушының ИП атауы
   - 12 таңбалы ЖСН/БСН
   - Төлем сомасы
5. ✅ Сәтті болса — курс каналына қолжетімділік беріледі
6. ❌ Сәтсіз болса — пайдаланушыға қате туралы хабарлама жіберіледі

## 🐳 Docker арқылы іске қосу

```bash
# 1. .env дайындау
cp .env.example .env

# 2. Контейнерді іске қосу
docker compose up -d --build

# 3. Логтарды тексеру
docker compose logs -f bot

# 4. Тоқтату
docker compose down
```
